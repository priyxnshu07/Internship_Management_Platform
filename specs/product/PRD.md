# Product Requirements Document
## Internship Management Platform

### Vision
A full-stack enterprise platform to manage intern lifecycle: onboarding → tasks → evaluation → offboarding.

### User Roles
- Super Admin (HR/Leadership)
- Mentor/Manager
- Intern
- Reviewer/Evaluator

### Core Features (MVP)
1. Auth & Role-Based Access Control (RBAC)
2. Intern onboarding workflow
3. Task/project assignment & tracking
4. Daily standup submissions
5. Mentor ↔ Intern messaging
6. Performance evaluation dashboard
7. Certificate generation on completion

### Out of Scope (v1)
- Mobile app
- AI recommendations
- Multi-tenant SaaS
